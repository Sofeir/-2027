# Путешествие 2027

Сайт с маршрутом, местами, походами с трекером, бюджетом, отелями, перелётами и списком вещей для поездки 20 мая – 22 августа 2027: Лос-Анджелес, Highway 1, Кремниевая долина, Аргентина, Боливия, Перу, Эквадор, Галапагос, Ереван.

## Что внутри

- `index.html` — готовая страница одним файлом (без внешних зависимостей, кроме шрифтов Google Fonts). Открывается в браузере напрямую.
- `src/p1.html` — разметка и стили.
- `src/p2.js` — этапы маршрута и места.
- `src/p3.js` — походы, бюджет, отели, перелёты, что рядом.
- `src/p3b.js` — погода, список вещей, визы и документы.
- `src/p4.js` — логика страницы.
- `build.sh` — собирает `index.html` из `src/`.

## Сборка

```sh
./build.sh
```

## Заметки

- Бюджет на двоих в шекелях, курс 3,11 ₪ за доллар (на 18.10.2026). Вилка 50–60 тысяч ₪: режим «Экономно» ≈ 55 тысяч, «Базовый» ≈ 64 тысяч.
- Цены на перелёты — диапазоны по агрегаторам, перед покупкой проверяйте живые цены.
- Правила виз и сборы Галапагосов проверяйте на официальных сайтах перед поездкой.
